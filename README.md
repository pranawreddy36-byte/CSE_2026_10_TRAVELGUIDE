
# 🌍 Tourism Guide – Explore India

A modern and interactive tourism guide web application that helps users discover popular tourist destinations across India, explore attractions, and view locations on interactive maps.

## ✨ Features

- 🏞️ Explore popular tourist destinations across India.
- 🔍 Search and discover destinations.
- 🗺️ Interactive maps for exploring locations.
- 📍 View destination information and details.
- 🧭 Travel guides for exploring tourist attractions.
- 🧮 Dijkstra's algorithm visualizer for shortest-path concepts.
- 📱 Responsive user interface for desktop and mobile devices.
- ⚡ Fast and modern web experience.

## 🛠️ Tech Stack

- **Next.js** – Web framework
- **React** – UI development
- **TypeScript** – Type-safe JavaScript
- **Tailwind CSS** – Styling
- **Leaflet** – Interactive maps
- **React Leaflet** – Map integration
- **Lucide React** – Icons

## 🚀 Getting Started

### Prerequisites

Install Node.js and npm before running the project.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

### 2. Navigate to the Project

```bash
cd tourism-guide
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run the Development Server

```bash
npm run dev
```

### 5. Open in Your Browser

Visit:

http://localhost:3000

## 🧠 Dijkstra Algorithm Visualizer

The application includes a visualization of Dijkstra's shortest-path algorithm, demonstrating how the shortest path between nodes can be calculated in a weighted graph with non-negative edge weights.
